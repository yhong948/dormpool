│          ▼                 ▼                                    │
│  ┌──────────────┐  ┌──────────────┐                            │

**数据流**：用户上传 zip → Master 按 `SHARD_SIZE` 切片 → Worker 主动 claim 分片
→ 子进程执行 → 结果上传 Master → 聚合为 `result.zip` → 用户下载

## 网络连接方式

| 项目 | 说明 |
|------|------|
| 拓扑 | 星形；Master 为中心，Worker 只出站，不监听入站 |
| 协议 | HTTP/1.1（uvicorn，无 TLS） |
| 绑定地址 | Master 绑定具体 LAN IP（拒绝 `0.0.0.0`）；Worker 无监听端口 |
| 防火墙 | Master 机器放行 TCP 8000 入站（`-Profile Private`）；Worker 机器无需改防火墙 |
| NAT 穿透 | 不需要；Worker 主动拉取天然穿过 NAT |
| 心跳 | Worker 每 10 s 一次；≥ 45 s 无心跳判定离线，任务自动回收并重新分配 |

## 快速启动（局域网双机）

```powershell
# Master 机器（WIN11）
.\scripts\start_master.ps1 -Bind 10.4.139.66 -Port 8000

# Worker 机器（另一台，克隆仓库后）
.\scripts\start_worker.ps1 -Master http://10.4.139.66:8000 -WorkerId worker-B
```

验证节点上线：

```powershell
# 应看到两条记录，conn_state 均为 online
Invoke-RestMethod http://10.4.139.66:8000/workers | ConvertTo-Json -Depth 5
```

## 安全边界

- Worker 只出站连接 Master，不开放任何入站端口
- Master 绑定具体 LAN IP，代码主动拒绝 `0.0.0.0`
- 所有进程只监听 `127.0.0.1` 或指定 LAN IP，不暴露公网
- Executor 只执行 `TASK_REGISTRY` 中注册的类型，无任意代码执行入口
- 路径防护：`/data/{ref}` 拒绝绝对路径与 `..`，无法逃出数据根目录
